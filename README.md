SHARE Folder Permissions Report
頂層共享資料夾權限報告 — 需求與功能規格書
文件版本：v1.0　　整理日期：2026-09-19
1. 專案目的
提供一個免安裝額外套件、以純 PowerShell 實作的工具，讓管理者/稽核人員能快速檢視某個共享路徑下，每個「頂層」資料夾的 NTFS 權限（讀 / 寫 / 完全控制），並產出一份可互動查看、也方便直接列印簽核的 HTML 報表。
2. 適用範圍與限制
•	只掃描指定目錄下的「第一層」子資料夾，不遞迴進入子資料夾內部。
•	只讀取每個頂層資料夾自身的 NTFS 存取控制清單（ACL）。
•	只統計「允許（Allow）」規則，暫不呈現「拒絕（Deny）」規則。
•	執行環境須為 Windows PowerShell（或 Windows 上的 PowerShell 7+），且執行帳號需有讀取目標資料夾 ACL 的權限。
3. 技術需求
•	純 PowerShell 原生指令實作，不依賴任何第三方模組（例如 ImportExcel）。
•	輸出格式為單一 HTML 檔案，雙擊即可用瀏覽器開啟，不需要額外安裝 Office / Excel。
•	若使用者想在 Excel 中檢視資料，可直接以 Excel 開啟該 .html 檔（Excel 可辨識 HTML 表格），再另存為 .xlsx。
•	預設掃描目錄＝腳本檔案自身所在目錄（不受執行 PowerShell 時所在工作目錄影響）。
•	預設輸出目錄＝腳本自身所在目錄，亦可用參數覆寫。
4. 參數規格
腳本提供以下參數，供調整掃描/輸出位置與預設排除清單：
參數	型別	預設值	說明
-TargetPath	string	腳本所在目錄	要掃描其頂層子資料夾的目錄
-OutputPath	string	腳本所在目錄	HTML 報表輸出目錄
-DefaultHiddenUsers	string[]	空陣列	報表開啟時，預先勾選為「排除」的使用者/群組名稱（支援萬用字元，例如 *SYSTEM*）
-DefaultHiddenFolders	string[]	空陣列	報表開啟時，預先勾選為「排除」的資料夾名稱（支援萬用字元）

5. 資料處理邏輯
•	1. 取得 -TargetPath 下所有「第一層」資料夾清單（不重複、依名稱排序）。
•	2. 對每個資料夾讀取其 NTFS 存取控制清單。
•	3. 篩選出「允許（Allow）」類型的規則，忽略「拒絕（Deny）」規則。
•	4. 將每條規則的權限歸類為以下三個維度（可同時具備多個）：
維度	對應 NTFS 權限	說明
Read（讀）	Read、ReadAndExecute	使用者可讀取該資料夾內容
Write（寫）	Write、Modify	使用者可寫入/修改該資料夾內容
Full Control（完全控制）	FullControl	完全控制，隱含讀取與寫入權限

•	5. 同一使用者對同一資料夾若有多條規則（例如顯式設定 + 繼承而來），會合併其權限，並固定依「Read → Write → Full Control」的順序顯示。
•	6. 收集所有出現過的「不重複」使用者/群組名稱，以及所有「不重複」的頂層資料夾名稱。
6. 報表輸出規格（HTML）
6.1 檔名與標題
•	報表標題（頁面標題與內文標題）與檔名皆固定為：SHARE Folder Permissions Report。
•	實際輸出檔名：SHARE Folder Permissions Report.html。
•	每次重新執行腳本，會覆蓋同名的舊檔案。
6.2 頁首資訊
•	顯示本次掃描的目錄路徑（Scan Directory）。
•	顯示報表產生的日期與時間（Generated），格式為 yyyy-MM-dd HH:mm:ss，例如 2026-09-19 15:32:10。
6.3 簽核欄位（供列印後手寫簽名）
於頁首日期時間下方，提供四個簽名欄位，僅顯示職稱標籤與空白底線，供列印後由相關人員親筆簽名：
•	GM
•	DGM
•	CISO
•	ISO
6.4 排除使用者區塊（Exclude Users）
•	列出所有掃描到的使用者/群組名稱，每個項目前方皆有核取方塊。
•	勾選某使用者後，該使用者對應的欄位（整欄）會從下方權限矩陣表格中隱藏。
•	提供「Exclude All」（全部排除）與「Show All」（全部顯示）兩個快捷按鈕。
•	報表開啟時，預設所有使用者皆顯示（不預先勾選任何人），除非透過 -DefaultHiddenUsers 參數指定預設排除清單。
6.5 排除資料夾區塊（Exclude Folders）
•	列出所有掃描到的頂層資料夾名稱，每個項目前方皆有核取方塊。
•	勾選某資料夾後，該資料夾對應的列（整列）會從下方權限矩陣表格中隱藏。
•	同樣提供「Exclude All」／「Show All」兩個快捷按鈕。
•	報表開啟時，預設所有資料夾皆顯示，除非透過 -DefaultHiddenFolders 參數指定預設排除清單。
•	「排除使用者」與「排除資料夾」兩項篩選條件可同時套用，彼此互不影響。
6.6 權限矩陣表格
•	第一欄固定為「Folder」，列出所有頂層資料夾名稱，且不重複。
•	表頭（第一列）列出所有不重複的使用者/群組名稱，且不重複。
•	每個儲存格顯示該使用者對該資料夾的權限組合，可能的顯示值包含：
◦	「-」（無對應的允許規則）
◦	Read
◦	Write
◦	Read,Write
◦	Full Control（隱含 Read 與 Write）
6.7 列印行為
•	使用瀏覽器「列印」報表時，「排除使用者」與「排除資料夾」兩個功能區塊會自動隱藏。
•	列印時僅保留：標題、掃描資訊、簽名欄位、權限矩陣表格，方便直接列印後供簽核。
7. 語言與呈現規則
•	HTML 報表畫面上顯示的所有文字（標題、按鈕、標籤、表頭、儲存格內容）一律使用英文。
•	PowerShell 腳本內部的註解，以及執行時於終端機顯示的提示訊息，維持中文（供維護者參考），不影響報表畫面的顯示內容。
8. 已知限制與未來可擴充方向（供後續開發參考）
•	目前僅呈現 Allow 規則，未顯示 Deny（拒絕）規則；如有需求，可另外新增欄位或以不同顏色標示。
•	目前僅掃描「第一層」資料夾；若未來需要遞迴至下一層或更深層，需另外設計呈現方式（例如樹狀結構或分頁瀏覽）。
•	目前不含原生 Excel（.xlsx）輸出；如需要真正的 Excel 檔案，須另外整合模組（例如 ImportExcel），或直接以 Excel 開啟現有 HTML 後另存新檔。
•	目前「排除使用者/資料夾」的勾選狀態僅存在於瀏覽器當前分頁，重新整理頁面會恢復成腳本產生當下的預設勾選狀態，並不會被永久保存。
•	若未來要交由他人接手開發，建議保留本文件作為需求基準，並同步附上目前的 .ps1 原始腳本作為實作參考。
